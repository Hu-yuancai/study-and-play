一、系统概述

1.1 项目简介

本项目是一个基于 ESP32-S3-DevKitC-1 开发板的多功能嵌入式娱乐学习设备，集成了三大功能模块：

🎹

钢琴游戏

音符从屏幕顶部下落，玩家通过矩阵键盘在判定线位置按下对应按键弹奏。命中产生对应频率的声音，支持连击加分。

✈️

飞机大战

经典纵向射击游戏。方向键控制飞机移动，按键发射子弹击落敌机。随等级提升，敌机速度和血量增加。

📚

学习伴侣

番茄工作法计时器，支持25/30/45/60分钟模式。OLED副屏显示动态表情鼓励学习，计时结束播放提醒音乐。

🔊

音频系统

通过ESP32 PWM输出方波，经LM386功放驱动扬声器。支持音符演奏、游戏音效、提醒铃声等多种音频输出。

关于Keil的问题

结论：Keil C51 无法用于ESP32开发。

Keil C51 编译器只能生成8051指令集的机器码。ESP32-S3使用的是Xtensa LX7架构（类似ARM）， 两者的CPU指令集完全不同，就像Windows的.exe不能在Mac上运行一样。

二、工作原理详解

2.1 ESP32 LEDC PWM 音频原理

这是本项目最核心的技术点之一，也是从C51项目继承并升级的关键模块。

C51的做法（定时器中断）：

// C51: 定时器1中断服务函数，手动翻转IO口
void Timer1_ISR() interrupt 3 {
    TH1 = freq_H;  // 重装初值高位
    TL1 = freq_L;  // 重装初值低位
    BEEP = !BEEP;  // 翻转蜂鸣器IO口
}
// 频率 = 11059200 / (12 * 2 * (65536 - 初值))

ESP32的做法（LEDC硬件PWM）：

// ESP32: 硬件自动产生指定频率的方波，CPU无需干预
ledcSetup(channel, 2000, 8);        // 初始化PWM通道
ledcAttachPin(AUDIO_PIN, channel);   // 绑定GPIO
ledcWriteTone(channel, 523);        // 输出523Hz方波 = 中音Do
原理相同，实现升级： 两者本质都是产生特定频率的方波驱动蜂鸣器/扬声器。 C51需要CPU不断响应中断来翻转IO，占用CPU时间；ESP32的LEDC模块是独立硬件， 设置好频率后自动运行，CPU可以去做其他事情（比如刷新游戏画面）。

2.2 LCD12864 (ST7920) SPI通信原理

LCD12864是128x64像素的点阵液晶屏，使用ST7920控制器。本项目通过SPI接口驱动（比C51项目的并口更省引脚）。

SPI通信时序：

ESP32 ST7920 LCD ───── ───────── GPIO18 (SCLK) ────────→ E (时钟) GPIO23 (MOSI) ────────→ RW (数据) GPIO5 (CS) ────────→ RS (片选) SPI数据格式 (每次传输3字节): ┌──────────┬──────────┬──────────┐ │ 同步字节 │ 数据高4位│ 数据低4位│ │ 0xF8/0xFA│ D7-D4+0 │ D3-D0+0 │ └──────────┴──────────┴──────────┘ 0xF8 = 写命令, 0xFA = 写数据
为什么用U8g2库？ ST7920的SPI协议比较特殊（串行数据需要拆分为高低4位分别发送）， 手写驱动容易出错。U8g2库已经封装好了所有底层时序，我们只需要调用高层API画图、写字即可。 而且U8g2内置了中文字库（wqy12），可以直接显示中文。

2.3 OLED (SSD1306) I2C通信原理

0.96寸OLED使用SSD1306控制器，通过I2C总线通信，只需要2根线（SDA数据 + SCL时钟）。

I2C总线结构: ┌─── 4.7kΩ ───┐ │ │ VCC ────────────────┤ ├──── VCC │ │ ESP32 GPIO21 (SDA) ─┼──────────────┼──→ OLED SDA │ │ ESP32 GPIO22 (SCL) ─┼──────────────┼──→ OLED SCL │ │ GND ────────────────┴──────────────┴──── GND I2C地址: 0x3C (出厂默认) 通信速率: 400kHz (Fast Mode)

2.4 4x4矩阵键盘扫描原理

矩阵键盘用8根线控制16个按键（4行+4列），比独立按键节省大量IO口。

扫描算法：

矩阵键盘物理布局: COL1 COL2 COL3 COL4 (GPIO27)(GPIO14)(GPIO12)(GPIO13) │ │ │ │ ROW1 ────┼───────┼───────┼───────┼──── (GPIO32) (GPIO32) │[1] │[2] │[3] │[A] │ │ │ │ ROW2 ────┼───────┼───────┼───────┼──── (GPIO33) (GPIO33) │[4] │[5] │[6] │[B] │ │ │ │ ROW3 ────┼───────┼───────┼───────┼──── (GPIO25) (GPIO25) │[7] │[8] │[9] │[C] │ │ │ │ ROW4 ────┼───────┼───────┼───────┼──── (GPIO26) (GPIO26) │[*] │[0] │[#] │[D] │ │ │ │ 扫描步骤: 1. 所有行设为OUTPUT，所有列设为INPUT_PULLUP 2. 逐行拉低: ROW1=LOW, 其余=HIGH 3. 读取所有列: 如果COL2=LOW → 按键[2]被按下 4. ROW1恢复HIGH, ROW2=LOW, 重复... 5. 加入50ms消抖延时，避免机械抖动误触发

2.5 LM386 音频功放原理

ESP32的GPIO输出电流很小（最大40mA），无法直接驱动扬声器发出足够音量。LM386是经典的小功率音频放大器，将微弱的PWM信号放大到可以驱动扬声器的功率。

信号流向: ESP32 GPIO4 ──→ [PWM方波 3.3V] ──→ LM386输入 ──→ [放大20倍] ──→ 扬声器 │ 增益=20(默认) 可通过1-8脚间 电容调至200 LM386典型电路: ┌────────────────────────────────┐ │ LM386 功放模块 │ │ │ IN+ ─────┤ 3 (非反相输入) │ │ 5 ────┤──→ 扬声器+ GND ─────┤ 2 (反相输入/地) │ │ 6 ────┤──→ VCC (5V) GND ─────┤ 4 (GND) │ │ │ └────────────────────────────────┘

四、详细接线指南

接线前必读：
  • 所有接线操作必须在 断电状态 下进行！
  • ESP32-S3的GPIO电压为 3.3V，LCD12864需要5V供电但信号兼容3.3V
  • 确认VCC和GND不要接反，否则会烧毁芯片！
  • 先接电源线（VCC/GND），再接信号线

五、实物搭建步骤（面包板版）

搭建原则：先供电，后信号；先单模块测试，后整体联调。每接好一个模块就测试一次，确认正常再接下一个。

5.1 搭建顺序（推荐）

  1. 准备面包板和ESP32开发板
    将ESP32-S3开发板插在面包板中间（跨越中间沟槽）。确保两侧引脚都能被杜邦线访问。 用USB-C线连接电脑，确认电脑能识别串口（设备管理器中出现COM口）。
  2. 接OLED副屏（最简单，2根信号线）
    OLED只有4根线：VCC→3V3, GND→GND, SCL→GPIO22, SDA→GPIO21。 接好后烧录测试程序，屏幕应显示内容。如果不亮，检查I2C地址是否为0x3C。
  3. 接LCD12864主屏（3根信号线+电源）
    确认PSB引脚已接GND（SPI模式）。接CS→GPIO5, SCLK→GPIO18, MOSI→GPIO23, VCC→5V, GND→GND。 背光BLA→5V, BLK→GND。烧录测试程序验证显示。
  4. 接4x4矩阵键盘（8根信号线）
    按照引脚表连接8根杜邦线。烧录键盘测试程序，按下每个键在串口监视器中打印对应键值。 如果某些键无反应，用万用表确认排线对应关系。
  5. 接LM386功放+扬声器（1根信号线+电源）
    GPIO4→LM386 IN+, 5V→LM386 VCC, GND→LM386 GND, LM386 OUT→扬声器。 烧录音频测试程序，应能听到声音。调节音量旋钮到合适大小。
  6. 烧录完整程序，整体联调
    所有模块接好后，烧录完整的esp32_game_machine.ino程序。 测试三个模式的切换和各功能是否正常。

LCD不显示任何内容PSB未接GND / 对比度未调确认PSB接地；调节V0电位器或直接V0接GND
LCD显示乱码SPI时序问题检查SCLK和MOSI是否接反；降低SPI速率

6.3 音频模块核心代码解析

// ESP32 LEDC PWM 产生方波的原理:
// LEDC本来是用来控制LED亮度的(PWM调光)，但我们利用它产生音频频率的方波
// ledcWriteTone() 会自动计算分频系数，输出指定频率的50%占空比方波

void playTone(uint16_t frequency, uint16_t duration) {
  if (frequency == 0) {
    ledcWrite(AUDIO_CHANNEL, 0);  // 频率0 = 静音(休止符)
    delay(duration);
    return;
  }
  ledcWriteTone(AUDIO_CHANNEL, frequency);  // 输出指定频率方波
  delay(duration);                          // 持续指定时长
  ledcWrite(AUDIO_CHANNEL, 0);              // 停止输出
}

// 对比C51的做法:
// C51: 手动计算定时器初值 → 中断翻转IO → CPU被中断占用
// ESP32: 一行代码设置频率 → 硬件自动输出 → CPU完全空闲

static void handleInput(uint8_t key) {
  for (int i = 0; i < MAX_NOTES; i++) {
    if (notes[i].active && notes[i].lane == lane) {
      int dist = abs(notes[i].y - JUDGE_LINE_Y);
      if (dist < 12) {  // 在判定范围内

        score += 100;                   // 加分
      }
    }
  }
}

6.7 开发环境配置

  1. 安装Arduino IDE 2.x
    从 arduino.cc 下载最新版Arduino IDE。安装完成后打开。
  2. 添加ESP32开发板支持
    菜单 → 文件 → 首选项 → 附加开发板管理器网址，添加：

7.2 分步调试策略

第一步：串口通信

烧录空程序，只保留Serial.begin(115200)和Serial.println("Hello")。 确认串口监视器能收到消息，说明开发板和电脑通信正常。

第二步：单独测试OLED

只接OLED，烧录OLED测试程序。如果不显示，用I2C Scanner扫描地址。 常见问题：SDA/SCL接反、地址不是0x3C而是0x3D。

第三步：单独测试LCD

只接LCD，烧录LCD测试程序。ST7920的SPI比较慢，如果显示不正常， 尝试在U8g2构造函数中降低时钟频率。

第四步：单独测试键盘

只接键盘，烧录键盘测试程序。逐个按键测试，在串口打印行列号。 如果某行或某列全部无反应，检查对应的杜邦线。

7.3 ESP32-S3 特殊注意事项

GPIO使用限制：
  • GPIO0: 启动模式选择引脚，不建议用作普通IO
  • GPIO1-GPIO20 (部分): 可能被内部Flash/PSRAM占用，具体看开发板原理图
  • GPIO34-39: 仅输入，不能输出（ESP32原版限制，S3版本无此限制）
  • GPIO43/44: 默认UART0 TX/RX，用于USB串口通信，不要占用
  • 建议使用的安全GPIO: 4, 5, 6, 7, 12, 13, 14, 15, 16, 17, 18, 21, 25, 26, 27, 32, 33
供电注意：
  • ESP32-S3 + LCD12864 + OLED + LM386 总电流约300-500mA
  • 电脑USB口通常能提供500mA，刚好够用
  • 如果出现不稳定（屏幕闪烁、重启），换用手机充电器（5V 2A）通过USB供电
  • LM386在大音量时电流较大，如果音频失真，给LM386单独供电

7.4 从C51项目借鉴的调试经验

原C51项目报告中提到的几个经典问题，在ESP32上同样可能遇到：

C51遇到的问题ESP32上的对应情况解决方案
蜂鸣器发声时影响温度传感器读数 LM386功放工作时可能产生电源纹波，影响I2C通信 LM386 VCC加100μF电解电容滤波；音频线和I2C线物理隔开
LCD显示屏对比度不对 ST7920的V0引脚电压不合适 V0接10kΩ电位器调节；或直接接GND（最大对比度）
按键消抖问题 矩阵键盘同样有机械抖动 软件消抖：50ms内不重复响应同一按键
定时器中断冲突 ESP32的LEDC通道冲突 音频固定使用LEDC通道0，不要和其他PWM功能冲突

7.5 进阶优化建议

  • 双核利用：ESP32-S3是双核CPU，可以把音频播放放在Core0，游戏逻辑放在Core1，实现真正的多任务
  • WiFi功能：利用ESP32的WiFi，可以实现在线排行榜、远程控制等功能
  • 蓝牙功能：可以连接蓝牙音箱输出更好的音质
  • SD卡扩展：加一个SD卡模块，可以存储更多曲谱和游戏关卡数据
  • 电池供电：加一个锂电池充放电模块，实现便携使用
