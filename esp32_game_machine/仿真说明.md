# 仿真使用说明（Wokwi for VS Code）

## 一次性环境准备

1. 装 VS Code
2. VS Code 扩展商店搜索安装：
   - **PlatformIO IDE**（首次安装会下载 ~200MB 工具链，等它装完）
   - **Wokwi Simulator**（Wokwi for VS Code）
3. 用 VS Code 打开 `esp32_game_machine` 文件夹
4. 第一次启动 Wokwi 会弹出 license 激活链接，浏览器里登录 GitHub 即可拿到 key（个人/学习免费）

## 仿真流程（每次写完代码这样跑）

```
Step 1  编译固件
   按 Ctrl+Alt+B  或  PlatformIO 侧栏 → Build
   产物：.pio/build/esp32-s3-devkitc-1/firmware.bin

Step 2  启动仿真
   按 F1 → 输入 "Wokwi: Start Simulator" → 回车
   或者直接打开 diagram.json，左上角点 ▶
```

仿真器窗口里能看到：LCD 显示菜单 → 鼠标点矩阵键盘上的按键 → 切换到飞机大战 → 飞机/敌机/子弹动起来 → 按键控制移动+开火。

## 飞机大战仿真要点（B 同学专用）

实物 4×4 键盘到 Wokwi 键位的映射（看 keyboard.cpp 里的扫描逻辑）：

| 实物按键 | Wokwi 键盘位置 | 功能 |
|---------|-------|------|
| KEY_UP    | 第1行第1列 | 飞机上移 |
| KEY_DOWN  | 第1行第3列 | 飞机下移 |
| KEY_LEFT  | 第1行第2列 | 飞机左移 |
| KEY_RIGHT | 第2行第2列 | 飞机右移 |
| KEY_FIRE  | 第2行第4列 | 开火 |
| KEY_BACK  | 第4行第4列 | 返回菜单 |

> 具体行列对应可能要按 keyboard.cpp 里的 `keymap` 数组对照——仿真启动后试一下就知道。

## Wokwi 能仿真什么 / 不能仿真什么

**能仿**：
- LCD12864 显示（用 SSD1306 替代，显示效果差不多，能验证 UI/动画逻辑）
- OLED 表情显示
- 4×4 矩阵键盘扫描、按键事件
- PWM 音频频率序列（用 buzzer 听节拍/音高，能验证音乐播放逻辑）

**仿不了**：
- LM386 功放电路、喇叭音质
- ST7920 真实的 SPI 时序（Wokwi 的 ST7920 元件不完整，所以用 SSD1306 替代）
- 电源纹波、地线干扰这类模拟问题

> 飞机大战的所有逻辑（按键响应、敌机生成、碰撞检测、计分、射击节奏）在 Wokwi 上 **100% 能验证**——这是仿真最大价值。

## 实物烧录

仿真验证 OK 后，用 USB-C 接好 ESP32-S3，按 Ctrl+Alt+U 上传，同一份代码直接跑实物。

## 常见问题

- **PlatformIO 第一次编译很慢**：要下载 espressif32 平台 (~500MB)，耐心等
- **Wokwi 找不到固件**：先 Build 一次，确认 `.pio/build/esp32-s3-devkitc-1/firmware.bin` 存在
- **LCD 显示是空的**：打开串口监视器（Ctrl+Alt+S）看 setup() 里有没有打印，确认初始化成功
- **Arduino IDE 也想能编**：留着 .ino 文件即可，PlatformIO 配置 `src_dir = .` 就是为了兼容
