# ESP32-S3 学习游戏一体机 — 完整操作手册

## 硬件概览

```
┌─────────────┐  ┌──────────────┐
│   OLED      │  │   TFT LCD    │
│  128×64     │  │  320×240     │
│  (副屏)     │  │  (主屏)      │
└─────────────┘  └──────────────┘
     ┌──────────────────┐
     │  4×4 矩阵键盘    │
     │  1 2 3 A        │
     │  4 5 6 B        │
     │  7 8 9 C        │
     │  * 0 # D        │
     └──────────────────┘
          蜂鸣器 (GPIO18)
```

| 部件 | 作用 |
|------|------|
| TFT LCD (320×240) | 主显示屏，显示游戏画面 |
| OLED (128×64) | 副显示屏，显示表情/状态 |
| 4×4 键盘 | 所有操作的输入设备 |
| 蜂鸣器 | 游戏音效和音乐 |

## 一、主菜单

开机后进入主菜单，LCD 显示 3 个游戏选项：

```
┌─────────────────────┐
│   Learning Game     │ ← 黄色标题栏
├─────────────────────┤
│ █ Piano Game        │ ← 绿色指示条=选中
│   Rhythm game...    │
│                     │
│   Minesweeper       │
│   Classic mine...   │
│                     │
│   Study Buddy       │
│   Pomodoro focus... │
├─────────────────────┤
│  UP/DOWN  ENTER     │
└─────────────────────┘
```

| 按键 | 功能 |
|------|------|
| **A** (↑) | 上一个选项 |
| **B** (↓) | 下一个选项 |
| **0** 或 **#** (ENTER) | 进入选中游戏 |
| 秘籍码 | 进入 Ghost Shell (见第五章) |

OLED 副屏显示当前选中模式的趣味描述文字。超过 1 分钟不操作会显示催促文字。

## 二、钢琴游戏 (Piano Game)

### 2.1 玩法简介

类似"节奏大师"的下落式音游。音符从屏幕上方落下，到达底部判定线时**按对应轨道的键**。

4 条轨道对应 4 个按键：
| 轨道 | 位置 | 按键 |
|------|------|------|
| 第 1 轨 | 最左 | **1** |
| 第 2 轨 | 左中 | **2** |
| 第 3 轨 | 右中 | **3** |
| 第 4 轨 | 最右 | **4** |

也可以用方向键：**C**(←)=轨道1, **A**(↑)=轨道2, **B**(↓)=轨道3, **D**(→)=轨道4

### 2.2 音符类型

| 类型 | 外观 | 操作 |
|------|------|------|
| **短按 (TAP)** | 白色方块 | 按一下即可 |
| **长按 (HOLD)** | 灰色长条 | 按住不放，持续到条尾 |

### 2.3 判定等级

| 等级 | 偏差 | 颜色 | 影响 |
|------|------|------|------|
| **Perfect** | ±72ms 内 | 金 | combo+1 |
| **Good** | ±128ms 内 | 绿 | combo+1 |
| **Bad** | ±160ms 内 | 橙 | combo 断 |
| **Miss** | 超时或没按 | 红 | combo 断 |

### 2.4 游戏操作

| 按键 | 功能 |
|------|------|
| **1/2/3/4** 或方向键 | 弹奏对应轨道 |
| **5** | 下一首曲目 |
| **6** | 上一首曲目 |
| **ENTER** | 暂停/继续 |
| **BACK** (*) | 返回主菜单 |

### 2.5 内置曲目

| 编号 | 曲名 | 难度 |
|------|------|------|
| 0 | 小星星 (Twinkle Star) | ★☆☆ |
| 1 | 生日快乐 (Happy Birthday) | ★★☆ |
| 2 | 音阶练习 (Scale) | ★☆☆ |
| 3 | 欢乐颂 (Ode to Joy) | ★★☆ |
| 4 | 铃儿响叮当 (Jingle Bells) | ★★★ |
| 5 | 玛丽有只小羊羔 (Mary's Lamb) | ★★☆ |

### 2.6 结算界面

歌曲结束后显示：
- 等级评定：S (≥95%) / A (≥85%) / B (≥70%) / C (≥55%) / D (<55%)
- Perfect/Good/Bad/Miss 各多少次
- 最大连击数 (Max Combo)
- 按 **ENTER** 重来

### 2.7 OLED 表情

| 情景 | 表情 | 含义 |
|------|------|------|
| 按 1/2/3/4 | 全屏角色 (phanion/mydei) | 按键反馈 |
| 左右同时按 | 融合角色 | 冲突效果 |
| Perfect | `(*^_^*)` | 开心 |
| Combo≥20 | `(*^_^*)` | 超开心 |
| Combo≥10 | `(O_O)` | 惊讶 |
| Combo≥5 | `(^-^)` | 眨眼 |
| Miss | `(>_<)` | 失误 |

## 三、扫雷游戏 (Minesweeper)

### 3.1 玩法简介

经典 Windows 扫雷。目标是**揭开所有没有地雷的格子**，不能踩到雷。

- 揭开格子 → 显示数字 (0-8)，表示该格周围 8 格中藏了几颗雷
- 数字=0 时 → 自动展开整片空白区域
- 在怀疑有雷的格子上**插旗**标记
- 揭开所有非雷格子 → 胜利！

### 3.2 界面

```
┌─────────────────────┐
│ Mines:18 Time:32    │ ← 顶部信息栏 (蓝底)
├─────────────────────┤
│ ██ ██ 1█ 2█ ...    │ ← 棋盘 (12×12 默认)
│ ██ ██ ██ 3█ ...    │ ← 绿色双框=光标
│ ...                 │
├─────────────────────┤
│ Arrows:move        │ ← 底部操作提示
│ ENTER:dig C:flag   │
└─────────────────────┘
```

### 3.3 操作

| 按键 | 功能 |
|------|------|
| **方向键** | 移动光标 (绿色双框) |
| **ENTER** (0/#) | 揭开当前格子 |
| **C** (右下角) | 插旗 / 取消旗子 |
| **1** | 简单模式 (8×8, 10雷) |
| **2** | 中等模式 (12×12, 20雷, 默认) |
| **3** | 困难模式 (16×16, 40雷) |
| **5** | 重新开始当前难度 |
| **BACK** (*) | 返回主菜单 |

### 3.4 OLED 表情

| 情景 | 表情 |
|------|------|
| 游戏中 | `(^_^)` / `(=_=)` 眨眼 |
| 胜利 | `\(^o^)/` / `(^_^)b` |
| 失败 | `(>_<)` |
| 作弊模式 | `(-_-)` 墨镜 |

### 3.5 存档

自动保存每难度的最佳时间(秒) + 总胜场/总局数到 ESP32 Flash，断电不丢失。

## 四、学习伴侣 (Study Buddy)

### 4.1 简介

番茄工作法计时器。选择一个专注时长，倒计时期间 OLED 每隔 5 分钟给一次鼓励。

### 4.2 操作

| 按键 | 功能 |
|------|------|
| **A** (↑) | 上一个选项 |
| **B** (↓) | 下一个选项 |
| **ENTER** | 选择/确认/开始/暂停/继续 |
| **BACK** (*) | 返回主菜单 |

### 4.3 界面流程

```
选择时长 → 倒计时 → 完成
  25min      12:30    Congratulations!
  30min      ████░░    Session: 25 min
  45min               Encouraged: 5 times
  60min               ENTER to continue
```

计时过程中按 **ENTER** 暂停，再按继续。完成后按 **ENTER** 回到选择界面。

### 4.4 OLED

- 选择/计时中: `(._.)` / `(-_-)zz` 眨眼
- 暂停: `(o_o;)`
- 完成: `\(^o^)/`

## 五、Ghost Shell 调试菜单（隐藏）

### 5.1 进入

主菜单输入秘籍码（**屏幕绝无提示**）：

```
A A B B C D C D 9 0
↑ ↑ ↓ ↓ ← → ← → FIRE ENTER
```

成功后蜂鸣器三声"滴滴滴"，进入十六进制内存编辑器。

### 5.2 内存编辑器

黑底绿字，每行 16 字节。方向键移动光标，数字键执行命令。

| 键 | 命令 | 功能 |
|----|------|------|
| **1** | Edit | 编辑光标字节 (hex/bin 逐位改) |
| **2** | Goto | 跳转到地址 |
| **3** | Base | 切换 HEX→DEC→BIN |
| **4** | Find | 搜索字节值 |
| **5** | Save | 保存到 Flash |
| **6** | Reset | 恢复默认值 |
| **7** | Hack | 进入参数快捷菜单 |
| **8** | Dump | 翻页 |
| **9** | Exit | 退出 (需确认) |
| **0** | Help | OLED 显示帮助 |

### 5.3 Hack 菜单 (按键 7)

```
HACK MENU
├── Minesweeper → 改棋盘大小/雷数/作弊/强制输赢
├── Piano Game  → 改曲目/速度/BPM/判定/自动弹奏/无敌
├── Display     → 改背景色/字体大小
└── [Back]
```

**两种调节方式：**

| 操作 | 按键 | 效果 |
|------|------|------|
| 精细调节 | ← → | 值 ±1 |
| **直接输入** | ENTER | 弹出 3 位数字编辑器，精确输入任意值 |

直接输入模式：`← →` 移动数位（百十个），`↑ ↓` 改数字，ENTER 确认。

### 5.4 参数速查

**扫雷参数：**
| 参数 | 地址 | 范围 | 默认 |
|------|------|------|------|
| Width | 0x21 | 8-16 | 12 |
| Height | 0x22 | 8-16 | 12 |
| Mines | 0x23 | 1~w*h/2 | 20 |
| Reveal | 0x24 | ON/OFF | OFF |

**钢琴参数：**
| 参数 | 地址 | 范围 | 默认 |
|------|------|------|------|
| Song | 0x30 | 0-5 | 0 |
| Scroll% | 0x31 | 50-200 | 100 |
| Perfect ms | 0x32 | 10-200 | 72 |
| AutoPlay | 0x33 | ON/OFF | OFF |
| NoMiss | 0x34 | ON/OFF | OFF |
| BPM | 0x35 | 60-240 | 120 |

**显示参数：**
| 参数 | 地址 | 范围 |
|------|------|------|
| BG Color | 0x10 | 0-6 (7色) |
| Font Size | 0x11 | 1-3 |

### 5.5 实战示例

**例1: 做个超简单扫雷 (8×8, 3颗雷, 透视)**

```
进入 Shell → 7 → Minesweeper → ENTER
Width:  ENTER → 输入 008 → ENTER
Height: ENTER → 输入 008 → ENTER
Mines:  ENTER → 输入 003 → ENTER
↓ Reveal → ENTER → ON
BACK → 5(保存) → 9 → 1(退出)
```

**例2: 钢琴自动弹奏+慢速练习**

```
进入 Shell → 7 → Piano → ENTER
↓ BPM: ENTER → 输入 080 → ENTER    (慢速)
↓ Scroll%: ENTER → 输入 060 → ENTER (音符下落慢)
↓ AutoPlay: ENTER → ON              (自动弹)
BACK → 5 → 9 → 1
```

**例3: 改黑底白字**

```
进入 Shell → 7 → Display → ENTER
BG: ←→ 切到 BLACK
Font: ENTER → 输入 003 → ENTER
BACK → 5 → 9 → 1
```

## 六、键盘物理布局速查

```
┌────┬────┬────┬────┐
│ 1  │ 2  │ 3  │ A  │   A = ↑ (方向键上)
├────┼────┼────┼────┤
│ 4  │ 5  │ 6  │ B  │   B = ↓ (方向键下)
├────┼────┼────┼────┤
│ 7  │ 8  │ 9  │ C  │   9 = FIRE, C = ← (方向键左)
├────┼────┼────┼────┤
│ *  │ 0  │ #  │ D  │   */#=特殊, 0=ENTER, D = → (方向键右)
└────┴────┴────┴────┘
```

| 丝印 | 游戏中通用功能 |
|------|--------------|
| **A** | ↑ 上 |
| **B** | ↓ 下 |
| **C** | ← 左 / 钢琴轨道1 / 扫雷插旗 |
| **D** | → 右 / 钢琴轨道4 |
| **1-4** | 扫雷难度 / 钢琴弹奏 |
| **5** | 扫雷重开 / 钢琴下一首 |
| **6** | 钢琴上一首 |
| **7** | 钢琴独有 |
| **8** | 钢琴独有 |
| **9** | 发射 / Ghost Shell 第9步 |
| **0** | ENTER 确认 |
| **#** | ENTER 确认 (与0相同) |
| **\*** | BACK 返回 |
