# ESP32-S3 学习游戏一体机

基于 ESP32-S3 的多功能掌上游戏机，集成钢琴节奏游戏、飞机射击游戏和番茄工作法计时器。双屏显示（ILI9341 彩屏 + SSD1306 OLED），4×4 矩阵键盘操控，PWM 蜂鸣器音效。

## 硬件

| 组件 | 型号 | 接口 | 引脚 |
|---|---|---|---|
| 主控 | ESP32-S3-DevKitC-1 | — | — |
| 主屏 | ILI9341 (240×320 竖屏) | SPI | CS:5, DC:16, RST:17, MOSI:35, MISO:37, SCK:36 |
| 副屏 | SSD1306 (128×64) | I2C (0x3C) | SDA:8, SCL:9 |
| 键盘 | 4×4 薄膜矩阵 | GPIO | ROW:6/7/10/11, COL:12/13/14/15 |
| 蜂鸣器 | 无源蜂鸣器 | PWM | GPIO 18 |

## 主菜单

开机进入彩色菜单界面，三个功能卡片：

- **Piano Game** — 节奏音乐游戏（Rhythm game with 4 keys）
- **Plane Battle** — 纵版射击游戏（Shoot-em-up arcade）
- **Study Buddy** — 番茄计时器（Pomodoro focus timer）

↑/↓ 切换，确认进入。OLED 副屏显示眨眼动画。按 * 随时返回主菜单。

---

## 模式一：钢琴游戏 (Piano Game)

### 玩法

- 4 条轨道，判定线在屏幕下方（Y=280），音符从上往下掉落
- 进入后显示曲目选择画面，按确认开始

### 音符类型

| 类型 | 操作 | 显示 |
|---|---|---|
| Tap（普通音符） | 到达判定线时按一下 | 白色方块 |
| Hold（长按音符） | 按住不放，合适时机松手 | 灰色长条 |

### 判定

| 评级 | 偏差 | Combo |
|---|---|---|
| Perfect ★ | ≤ 72ms | +1 |
| Good :) | ≤ 128ms | +1 |
| Bad :( | ≤ 160ms | 清零 |
| Miss | > 160ms / 漏键 | 清零 |

### 进阶操作

- **5/6** — 切换曲目（共 6 首）
- **确认** — 暂停/继续
- 按住键盘上的 **1+2** 或 **3+4** 组合键可在 OLED 上触发全屏角色动画（phanion / mydei 系列）

### 曲目列表

1. Twinkle Star（小星星）
2. Happy Birthday（生日快乐）
3. Test Hold（长按练习）
4. Ode to Joy（欢乐颂）
5. Jingle Bells（铃儿响叮当）
6. Mary's Lamb（玛丽有只小羊羔）

### 结算

全部音符结束后显示成绩单，含：
- **评级**（S/A/B/C/D，≥95% 为 S）
- ACC 准确率、最高 Combo、P/G/B/M 分项统计
- 按确认重新开始

## 模式二：飞机大战 (Plane Battle)

### 玩法

控制底部战机射击上方下落的敌机。

| 操作 | 按键 |
|---|---|
| 四方向移动 | A/B/C/D（← → 可长按连续移动） |
| 射击 | 9 或确认 |

### 规则

- 初始 **3 条命**，等级 Lv.1
- 击毁敌机得分 = `10 × 当前等级`
- 敌机穿过底线或撞击玩家 → 扣 1 条命
- 生命归零 → 游戏结束
- 每约 10 秒升一级：敌机加速、血量增加
- 游戏结束按确认重新开始

---

## 模式三：学习伴侣 (Study Buddy)

### 使用流程

1. **选择时长** — ↑/↓ 在 25/30/45/60 分钟中选择，不同时长以不同颜色高亮
2. **专注计时** — 主屏显示大字号倒计时 + 进度条；每 5 分钟 OLED 眨眼鼓励
3. **暂停** — 按确认暂停/继续
4. **完成** — 计时归零后播放成功旋律，显示 Session 时长和鼓励次数

---

## OLED 副屏说明

OLED 作为辅助显示屏，在不同场景显示不同内容：

- **菜单** — 待机眨眼动画
- **钢琴游戏** — ACC 和 P/G/B/M 统计 + 表情反馈；组合按键触发全屏角色
- **飞机大战** — 分数和生命
- **学习伴侣** — 专注/暂停/完成等不同眨眼表情

## 开发

### 编译烧录

```bash
pio run                  # 编译
pio run --target upload  # 烧录
pio device monitor       # 串口监视（115200）
```

### 依赖

- **U8g2** (olikraus/U8g2@^2.36.18) — OLED 驱动
- **Adafruit GFX Library** (@^1.11.0) — 图形基类
- **Adafruit ILI9341** (@^1.6.0) — LCD 驱动

### Wokwi 模拟

安装 Wokwi VS Code 插件后可直接模拟运行，模拟配置见 `diagram.json` + `wokwi.toml`。

### 项目结构

```

│   ├── plane_game.h        # 飞机大战

    ├── lcd_driver.cpp      # LCD 帧缓冲渲染
```

### 添加钢琴曲目

在 `src/piano_game.cpp` 中：

1. 定义 `NoteProto` 数组（`{tick, 轨道0-3, 0=Tap/1=Hold, 持续时长}`），以 `{0xFFFFFFFF,0,0,0}` 结尾
2. 注册到 `songData[]` 和 `songNames[]`
3. 更新 `MAX_SONGS` 和 `songLengths[]`
